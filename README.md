# Anay Goyal — Portfolio

A personal portfolio website built with React and Vite, showcasing my projects, skills, and journey as a Computer Science undergraduate at IIIT Pune.

## 🌐 Live Demo

[View Portfolio](https://anaygoyal9.github.io/Portfolio/)

## 🛠️ Tech Stack

- **React 19** — UI library
- **Vite** — Build tool and development server
- **CSS** — Custom styling with CSS variables

## ✨ Features

- Fully responsive design
- Mobile-friendly navigation
- Animated SVG rating graph in the hero section
- Dark theme with a purple/violet accent palette
- About section
- Skills section
- Career timeline
- Projects showcase
- Contact section
- Resume download
- Smooth navigation between sections
